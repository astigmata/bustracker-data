# bustracker-data

Generated data bundle for the **bustracker** Android app (Montpellier / TaM). Published daily by CI
from the official GTFS feeds; the app polls `manifest.json` and installs any newer copy, so schedule
changes reach installed apps without a store update.

Do not edit by hand — every file here is overwritten by the next run.

Sources: TaM Montpellier 3M (Licence Ouverte), liO Occitanie, Transp'Or Pays de l'Or, SNCF Open
Data, OpenStreetMap contributors (ODbL).
